Recommended download

git clone -b maint https://gitlab.com/petsc/petsc.git petsc

  • Use git pull anytime to obtain new patches that have been added since your git clone or last git pull.
  • Use git checkout v3.13.5 to checkout a particular version.

Please join the petsc-announce and petsc-users mailing lists.

Documentation of changes/patches

  • Documentation of patches in 3.13
  • Summary of PETSc 3.12 to 3.13 additions and changes

Downloads if you cannot use git

  • petsc-lite-3.13.5.tar.gz (use with online documentation)
  • petsc-3.13.5.tar.gz (includes documentation, recommended for those with slow internet connections)
If GitLab and our primary download server is unavailable
  • https://www.mcs.anl.gov/petsc/mirror/release-snapshots/

PETSc development repository

You can work with the development version of PETSc, You decide when to update to the lasted code in the repository. This also facilitates easy submission of fixes and new features to the development team.

Older releases of PETSc are also available, these should only be used for applications that have not been updated to the latest release. We urge you, whenever possible, to upgrade to the latest version of PETSc
