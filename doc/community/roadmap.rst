*************
PETSc Roadmap
*************

Planned major focus areas for PETSc development include

* GPU support including NVIDIA, AMD, and Intel systems.

* Derivative enhanced software. That is more support in all components of PETSc and PETSc simulations for providing and conveying
  derivative information and making it available to the user and other packages. This can include algorithmic (e.g. ``TSAdjoint``) and
  automatic differentiation.

* Batching. Efficiently solving many related problems together using potentially multiple levels of parallelism.

* Enhanced language bindings

  * Easier Python usage including transparent interoperability with **Numpy**, PyTorch, JAX, and TensorFlow.

  * Julia bindings

* Interoperability with machine learning software including PyTorch, JAX, and TensorFlow.
